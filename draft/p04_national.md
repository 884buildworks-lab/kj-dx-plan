# 4. 国・県の動向と法的要請

**国は自治体DX推進計画 第5.1版（令和8年1月30日改定）で重点8取組を提示。** 計画期間は固定を撤廃し、取組スケジュールを毎年度更新する方式へ。加えて**改正地方自治法により令和8年度からサイバーセキュリティ確保の方針策定が義務化**〔施行日・公表義務の条文根拠は要確認〕。基幹20業務の標準化は原則令和7年度末が移行目標。宮崎県は「みやざきDXプラン」で市町村を伴走支援する。**町計画はこれらに整合させ、上位施策との紐づけを明示する。**

## 自治体DX推進計画 第5.1版 重点8取組

| # | 取組 | 木城町の中核方針との関係 |
|---|---|---|
| ① | 自治体フロントヤード改革 | **公式アプリの共通接点化がここに位置づく** |
| ② | 情報システムの標準化 | 基幹20業務の移行（p9） |
| ③ | 国・地方デジタル共通基盤 | 共通化の追随 |
| ④ | 公金収納でのeL-QR活用 | 手続きDXの一部 |
| ⑤ | マイナンバーカード利用推進 | 本人確認・手続き連携 |
| ⑥ | セキュリティ対策の徹底 | 方針策定義務（p10） |
| ⑦ | AIの利用推進 | 内部業務効率化（p9） |
| ⑧ | テレワークの推進 | 少数職員の働き方 |

## 期限のある法的要請

| 事項 | 期限 | 確度 |
|---|---|---|
| サイバーセキュリティ確保の方針策定 | **令和8年度から義務**（改正地方自治法・令和6年法律第65号） | 施行日2026-04-01・公表義務は【要確認】 |
| 基幹20業務の標準準拠システム移行 | 原則 **令和7年度末**（特定移行支援システムは概ね5年以内） | 事実 |
| サイバーセキュリティ基本方針の策定・公表 | 2026年4月1日から | 要確認 |

## 県の支援（財源・人材制約の緩和策）

- **みやざきDXプラン**（令和7年3月・計画期間R7〜R10）。町計画の期間と整合。
- **宮崎県市町村IT推進連絡協議会**（26市町村構成）を通じ、共同調達・共同利用・専門人材派遣・伴走支援を活用できる立場〔事実〕。
