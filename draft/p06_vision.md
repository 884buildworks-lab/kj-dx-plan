# 6. ビジョンと基本方針 — 公式アプリを生活の基盤に

**デジタル未来宣言（2024年）を具体化し、公式アプリを「住民生活の利便性向上の基盤」に育てる。** 新規のバラバラなシステム開発ではなく、既にある公式アプリを共通接点・共通基盤として集約する方向で描く。目指す姿は **「接点を集約し、少数職員で回し、誰も取り残さない」**。この実現のため、施策を3本柱に整理し、全柱を貫く原則として「重要情報の多重化」を置く。

## ビジョン

> **公式アプリを軸に、町政・生活・防災の情報とサービスを一つの入口に集約し、少人数の役場でも住民の利便性を高め続ける町へ。**

## 3本柱

| 柱 | 内容 | 対応ページ |
|---|---|---|
| **柱1｜情報発信の主軸化** | 乱立チャネルを公式アプリへ集約し、到達率を上げる | p7・p8 |
| **柱2｜サービス提供の基盤化** | 手続き・予約・相談・防災をアプリに集約し生活利便を高める | p7 |
| **柱3｜少数職員で回す内部改革** | BPR・基幹20業務標準化・セキュリティで負荷と法対応を両立 | p9・p10 |

## 全柱を貫く原則（数値KPIには置かないが本文に明記）

- **アプリで届く分は最大化し、なお伸ばす。** 一方で**災害情報など重要な情報・サービスはアプリに依存せず多重化を継続維持**する（Yahoo!防災速報・防災無線・紙・窓口）。
- 多重化は"弱点の言い訳"ではなく**設計上の冗長性**。アプリ満額でも緊急時の実到達は人口の約4割どまり〔推定・p7〕という事実と整合させる。

## 上位計画との整合

- 第六次総合計画（前期R7〜R11）・第5次行財政改革大綱（R6〜R9）・国のDX推進計画第5.1版フロントヤード改革①と整合〔事実〕。
