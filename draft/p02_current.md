# 2. 木城町の現状 — 人口減・高齢化・少数職員

**人口4,409人・1,783世帯（令和8年8月）。国勢調査では35年で約1,200人減。** 高齢化率は令和2年国勢調査で37.2%〔事実〕、住民基本台帳ベースの令和5年度値は38.78%〔要確認〕。年少人口割合15.02%は県内2位で、子育て層の相対的厚みが特徴。役場を支える正規職員は88人（令和4年）、うち40歳以上が61.4%。**人口減・高齢化に、増やせない少数職員で対応する構造**であり、DXは「人を増やさず住民サービスを維持する手段」に位置づく。
