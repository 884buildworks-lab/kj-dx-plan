### 1. 自治体DX推進計画 第5.1版

| 項目 | 内容 |
| --- | --- |
| 制度名 | 自治体デジタル・トランスフォーメーション（DX）推進計画【第5.1版】（総務省） |
| 要点 | 2026年（令和8年）1月30日改定。前身の第5.0版（令和7年12月17日）に最新の政策・予算等を反映した版。重点取組は8項目。計画本体は「国の動向を反映させるよう適宜見直し」、別紙2の「自治体の主な取組スケジュール」を5年間を目途に設定し毎年度更新。計画記載事項は地方自治法第245条の4第1項に基づく技術的助言。 |
| 重点取組8項目 | ①自治体フロントヤード改革の推進 ②地方公共団体情報システムの標準化 ③「国・地方デジタル共通基盤の整備・運用に関する基本方針」に基づく共通化等の推進 ④公金収納におけるeL-QRの活用 ⑤マイナンバーカードの取得支援・利用の推進 ⑥セキュリティ対策の徹底 ⑦自治体のAIの利用推進 ⑧テレワークの推進 |

| 要点 | 地方公共団体はサイバーセキュリティの確保の方針を定め、必要な措置を講ずる旨が地方自治法に規定された。総務大臣が方針策定等の指針を示す。DX推進計画第5.1版は「令和6年改正地方自治法に基づき、令和8年度より、方針の策定が義務付けられている」と記載。関連ガイドラインは「地方公共団体における情報セキュリティポリシーに関するガイドライン」（総務省、令和6年10月改定）。 |

| 木城町への含意 | 令和8年度中にサイバーセキュリティ確保の方針の策定（必要なら公表）が必要。既存の情報セキュリティポリシーの改定・整備で対応する形が想定される。担当課・工数の記載時に、この法的義務を根拠として明示できる。 |

### 3. 基幹20業務システムの標準化

| 項目 | 内容 |
| --- | --- |
| 制度名 | 地方公共団体情報システムの標準化に関する法律（令和3年法律第40号）／地方公共団体情報システム標準化基本方針（令和6年12月改定） |
| 要点 | 住民基本台帳・戸籍・地方税（個人住民税/法人住民税/固定資産税/軽自動車税）・国民健康保険・介護保険・後期高齢者医療・国民年金・児童手当・子ども子育て支援・生活保護・障害者福祉・児童扶養手当・健康管理・就学・選挙人名簿管理・印鑑登録・戸籍の附票 等の20業務が対象。標準準拠システム利用を義務付け。 |
| 期限 | 原則 **令和7年度（2025年度）末** までに標準準拠システムへ移行を目指す。移行完了後、運用経費を平成30年度（2018年度）比で少なくとも3割削減を目指す。 |
| 特定移行支援システム | 令和8年度（2026年度）以降の移行とならざるを得ないことが具体化したシステムは「特定移行支援システム」とし、所要の移行完了期限を設定、概ね5年以内（2030年度末目途）に移行できるよう国が積極支援。該当見込みは全34,592システムのうち3,770システム（10.9%）・643団体（36.0%）＝令和7年7月末時点（デジタル庁公表 令和7年9月30日）。※直近の令和7年12月公表で約5,009システム（14.5%）に増加との報道あり、一次確認は要【要確認】。 |
| 木城町への含意 | 20業務は町の基幹システムであり、標準化・ガバメントクラウド移行は町計画の前提。公式アプリ基盤の方針とは別レイヤーだが、移行に伴う運用経費・職員負担は施策の工数・費用見積りに影響する。町システムの移行状況（期限内／特定移行支援システム該当）を庁内ヒアリングで確認要。 |
| 出典URL | デジタル庁提出資料「地方公共団体の基幹業務システムの統一・標準化について」（令和7年11月18日 第44回国と地方のシステムWG）https://www5.cao.go.jp/keizai-shimon/kaigi/special/reform/wg6/2025/shiryou3-2.pdf ／ デジタル庁 標準化トップ https://www.digital.go.jp/policies/local_governments |
